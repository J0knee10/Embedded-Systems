1. Toolkit

Σ∞n=0 qn = 11−q (|q|<1) Σ∞n=1 qn = q1−q
ΣN−1n=0 qn = 1−qN1−q (q≠1)
  • Geometric: first term/(1 − ratio), |ratio| < 1. Σa..bqn = (qa − qb+1)/(1−q). Σn≥0(az−1)n = z/(z−a) if |z| > |a|; Σn≥1(z/a)n = (z/a)/(1−z/a) if |z| < |a|; z = ejΩ → DTFT.
  • Euler: cos θ = (ejθ + e−jθ)/2, sin θ = (ejθ − e−jθ)/(2j). 1/j = −j, ejπ/2 = j, ejπ = −1.
  • Sampling: x[n] = xc(nTs), Ts = 1/fs. Ω = ωTs = 2πf/fs (rad/sample).
  • Period of cos(Ω0n): write Ω0/2π = m/N in lowest terms → N0 = N (the denominator).
    • sin(πn/12): 1/24 → N0 = 24. cos(3.5πn): 7/4 → N0 = 4.
    • Ω0/2π irrational (e.g. cos(n)) → not periodic.
  • Sum of periodic signals: N0 = LCM(N1, N2).
  • Nonzero periodic signal is never absolutely summable (Σ|x| adds the same block forever).
  • Aliasing: Ω, Ω + 2πk and (for cos) −Ω give identical samples. In Hz: f, f + k·fs, fs − f look the same.
    • e.g. cos(3.5πn) = cos(−0.5πn) = cos(0.5πn).
    • Unique only if 0 ≤ Ω ≤ π, i.e. f < fs/2. Nyquist: fs > 2fmax.

  • LTI causal ⇔ h[n] = 0 for n < 0. LTI stable ⇔ Σ|h[n]| < ∞.
  • Convolution facts: x ∗ δ[n−k] = x[n−k]. x ∗ u = running sum Σm≤n x[m]. u ∗ u = (n+1)u[n] (Σmu[m]u[n−m] counts m = 0…n → n+1).
  • Step → impulse response: s = T(u) ⇒ h[n] = s[n] − s[n−1] (because δ[n] = u[n] − u[n−1]).
  • Length: linear conv of Lx and Lh samples has Lx + Lh − 1 samples.
  • FIR: no y on the right; h = the coefficients; all poles at z = 0; always stable.
  • IIR: feedback (y[n−k] on the right); h never ends; stable only if all poles inside |z| = 1.

3. DFT and DTFS

  • N = 4: X = (matrix)·x. Synthesis x = ¼·(same matrix with j ↔ −j)·X.

  • Quick values: X[0] = Σx[n]. x[0] = (1/N)ΣX[k]. N = 4: X[2] = x0 − x1 + x2 − x3.
  • Real x: X[N−k] = X[k]* (N = 4: X[3] = X[1]*); X[0] and X[N/2] are real. Rows 1 and 3 are conjugates.
  • Unknowns in x and X (T02 Q1d style): fill in X[3] = X[1]* first, then use one synthesis row for a known x value.
  • DTFS: same formulas, valid for all n only if N is a period (multiple of N0); otherwise the repeated block ≠ the signal (leakage).
  • N0 vs N: N0 = signal's period (calculate). N = DFT size (choose). No leakage ⇔ N is a multiple of N0.
  • DTFS by Euler (no sum): write x as a sum of ej2πkn/N; then X[k] = N × (coefficient of ej2πkn/N). Use e−j2πn/N = ej2π(N−1)n/N.
    • e.g. cos(2πn/8) = ½ej2πn/8 + ½ej2π·7n/8 → X[1] = X[7] = 8 × ½ = 4.
    • For sin: 1/(2j) = ½e−jπ/2.

4a. Circular Convolution

  • Multiplying DFTs gives circular convolution: IDFTN{X[k]·Y[k]} = x ⊛N y, not the linear one.
  • Wrap rule: C[n] = L[n] + L[n+N] (+ L[n+2N] …): fold the tail of the linear result L back onto its start.
    • e.g. L = [−2, 1, 3, −6, 2, 8], N = 4 → C = [−2+2, 1+8, 3, −6] = [0, 9, 3, −6].
  • Circular = linear: zero-pad both to N ≥ Lx + Ly − 1.

4b. The DTFT

analysisX(Ω) = Σ∞n=−∞ x[n] e−jΩn
synthesisx[n] = 12π ∫2π0 X(Ω) ejΩn dΩ
  • Repeats every 2π in Ω (so the synthesis ∫ can be over any 2π window: 0→2π or −π→π). Exists if Σ|x[n]| < ∞; u[n], 2nu[n] and periodic signals fail.
  • Pairs (|a| < 1):
    • anu[n] ↔ 1/(1 − a·e−jΩ). Why: ane−jΩn = qn with q = a·e−jΩ, |q| = |a|·|e−jΩ| = |a| (|ejθ| = 1 always) → Σqn = 1/(1−q) needs |a| < 1. T02 Q3: a−nu[n] → q = a−1e−jΩ, |q| = 1/|a| < 1 ⇔ |a| > 1.
    • a−nu[−n−1] ↔ a·ejΩ/(1 − a·ejΩ)
    • (n+1)anu[n] ↔ 1/(1 − a·e−jΩ)² (= x ∗ x)
  • Shift: x[n−k] ↔ e−jΩk·X(Ω) (size same, only phase changes).
  • Convolution → product: Y(Ω) = H(Ω)·X(Ω). H(Ω) = DTFT of h = H(z) at z = ejΩ.
  • One frequency in → same frequency out: ejΩ0n → H(Ω0)·ejΩ0n. |H| = gain, ∠H = phase shift.

9. Q&A Notes (things I asked about)

  • Period rule: Ω0N = 2πm (N samples, m full laps, both whole); smallest m making N whole. Ω0/2π = f/fs = cycles per sample; periodic ⇔ rational. Lowest terms: bottom = N0, top = cycles.
  • Simplify first: the rule gives when the walker returns; it overcounts only if every sample is 0: sin(πn) = sin(3πn) = 0 has period 1 (rule says 2). A sign on Ω or ±2π aliasing doesn't change N0. cos(−θ) = cos θ; sin(−θ) = −sin θ.
  • Ts ≠ T0 ≠ N0: Ts = 1/fs (sampler, s); T0 = 1/f (wave, s); N0 (samples, whole number). N0·Ts = m·T0.
  • Causal, formally: if x = z up to time N, then the outputs are equal up to N. In practice: every x[·] index ≤ n for every n. Traps: x[2n], x[−n]. n·x[n] is fine.
  • Linearity: T(a·x1 + b·x2) = a·Tx1 + b·Tx2, where a, b scale values (x[an] is time scaling, a different thing). Disprove with 1 counterexample that switches on the suspect term: for x[n]x[n−1], use v = δ[n] + δ[n−1]: T(v)[1] = 3, T(2v)[1] = 8 ≠ 6. Prove with algebra: product terms leave (a²−a)pq + (b²−b)rs + ab(ps + rq), via a²pq = a·pq + (a²−a)pq.
  • Convolution means: x = Σ x[m]δ[n−m]; each kick sends out x[m]·h[n−m]; add the copies (LTI only). [2, 1] ∗ [1, 2, 3] = [2, 5, 8, 3].
  • Running sum, h = u (§2): u in → (n+1)u[n] out. Bounded in, unbounded out → unstable (pole at z = 1).
  • Signal or system? Transform a signal → X: what it contains. Transform h → H: what the system does to each frequency. Y = H·X. ROC for a signal → which side, whether the DTFT exists; for a system → causal, stable.
  • DFT as matrices: ω = ej2π/N (N = 4: ω = j), G[n,k] = ωnk; GH = conjugate transpose (G symmetric → just j ↔ −j). X = GHx (analysis: row k · x = X[k]); x = (1/N)·G·X (synthesis); works because G·GH = N·I. Why −j: the opposite spin stops a matching walker (jn(−j)n = 1 each time, sums to N); any other frequency cancels to 0.

5. Z-transform and its Pairs

analysisX(z) = Σ∞n=−∞ x[n] z−n,z = r·ejΩ
synthesis (any r in ROC)x[n] = rn2π ∫2π0 X(rejΩ) ejΩn dΩ
  • Meaning: X(rejΩ) = DTFT of the faded signal r−n·x[n]. |z| = r = fading, ∠z = Ω = frequency. On |z| = 1: X(ejΩ) = DTFT.
  • Undo the fading: if W(Ω) = X(rejΩ) then w[n] = r−nx[n], so x[n] = rn·w[n] (= the synthesis formula; in practice invert with §7).
  • Tags: finite list → X(z) = Σ x[n]z−n. Coefficient of z−k = x[k] (future); of z+k = x[−k] (past).
  • Same thing, two forms: z/(z−p) = 1/(1 − p·z−1).
  • DTFT inside X(z): the Ω axis from −π to π wraps round the unit circle (Ω = 0 → z = 1, π/2 → j, ±π → −1). DTFT = 1 dial (Ω); Z = 2 dials (r, Ω). Building blocks are spirals zn = rnejΩn; a pole p means the signal contains pn. e.g. 2nu[n] faded with r = 4 gives 0.5n (works for any r > 2, which is the ROC).

6. Poles, Zeros and ROC Rules

  • Poles = roots of the denominator (×); zeros = roots of the numerator (○). First make ONE fraction in +powers of z and cancel: zeros hide in sums (z/(z−0.6) + z/(z−1.2) = 2z(z−0.9)/(…)). LCCDE: x-terms → zeros, y-terms → poles.
  • ROC is a ring r1 < |z| < r2 with edges at poles; never contains a pole.
  • Which ring: right-sided → outside the outermost pole · left-sided → inside the innermost pole · two-sided → a ring between poles (can be empty: 2|n| needs |z| > 2 and |z| < ½ → no ROC) · finite length → all z except maybe 0 and ∞.
  • P poles at different radii → P + 1 possible ROCs, each a different x[n].
  • Which way each pole runs: pole inside the ring (|p| ≤ inner edge) → right-sided pnu[n]; pole outside (|p| ≥ outer edge) → left-sided −pnu[−n−1].
  • Stable (DTFT exists) ⇔ unit circle |z| = 1 is in the ROC. A pole on |z| = 1 (e.g. z = 1) → no DTFT.
  • Causal ⇔ ROC is outside the outermost pole and includes ∞ (numerator degree ≤ denominator degree in z).
  • Causal and stable ⇔ every pole strictly inside the unit circle.

7. Inverting X(z)

  1. Factor the denominator → poles. Mark the ROC's edges.
  2. Numerator has a factor z: expand X(z)/z = C/(z−p) + D/(z−q) → X(z) = C·z/(z−p) + D·z/(z−q) → pn-type terms.
  3. No factor z: expand X(z) = C/(z−p) + D/(z−q) → pn−1u[n−1]-type terms.
  4. Cover-up: C = [(z−p) × the fraction being expanded] at z = p.
  5. Choose each term's side from the ROC (section 6), then write x[n].
  6. Special denominators: repeated (z−p)² → n·pn or (n+1)pn pairs · quadratic z² − 2ρz·cosΩ0 + ρ² → cos/sin pairs (ρ² = constant term, then cosΩ0 from the middle) · only z² appears → set w = z², do partial fractions in w.
Example: X(z) = z/((z−½)(z−2)), |z| > 2. X/z = 1/((z−½)(z−2)): C = 1/(½−2) = −⅔, D = 1/(2−½) = ⅔. Both poles inside the ring → right-sided: x[n] = [−⅔(½)n + ⅔·2n]u[n].

Series expansion (first few samples, right-sided): long-divide in powers of z−1; x[n] = coefficient of z−n. e.g. (1 + z−1)/(1 − ½z−1) = 1 + 1.5z−1 + 0.75z−2 + 0.375z−3 + … → x[0..3] = 1, 1.5, 0.75, 0.375.

Checks: causal x: x[0] = limz→∞ X(z). Plug in n = 0, 1 and compare.

9. Q&A Notes (continued)

  • Why poles are ROC edges: pole p ⇔ signal has pn (×p each step); Σ(p/z)n needs |z| > |p| → edge |z| = |p|.
  • 1st-order LCCDE: pole = number before y[n−1] (y = 0.5y[n−1] + x → z/(z−0.5)).
  • Zero: input zn → output 0.
  • ROC = adds up with weight z−n; stable = with no weight (|z| = 1). A blowing-up h can still have an ROC (Lab 4 Region 0).
  • sin or cos route, same X[k]: sin θ = cos(θ − π/2), and 1/j = e−jπ/2 does the same −π/2 turn. T02: sin(2πn/6 + π/3) = cos(2πn/6 − π/6) → weights ½e∓jπ/6.

8. Difference Equations (LCCDEs)

No initial conditions (bilateral, LTI) → H(z)

  1. Transform every term: y[n−k] → z−kY, x[n−k] → z−kX.
  2. H(z) = Y/X = (b0 + b1z−1 + …)/(1 + a1z−1 + …). Multiply top and bottom by the highest power of z to read the poles.
  3. One H(z), several ROCs → several systems; use section 6 for causal/stable. Leftover positive power of z on top (from x[n+1]) → not causal for any ROC.
  4. H = z−k·G ⇒ h[n] = g[n−k]: invert G, then shift.

With initial conditions (unilateral, n ≥ 0)

unilateralY+(z) = Σ∞n=0 y[n] z−n

Shift rules Z+{y[n−1]}, Z+{y[n−2]} are given in the paper. An input starting at n = 0 has X+ = its usual right-sided pair.

Recipe

  1. Transform both sides with the shift rules.
  2. Collect: Y+·(1 + a1z−1 + …) = X+ − (initial-condition terms).
  3. Zero-input: initial-condition terms ÷ (1 + a1z−1 + …). Zero-state: H·X+.
  4. Partial fractions (w = z² if only z² appears), invert with right-sided pairs (n ≥ 0).
  5. Complete: y = yzi + yzs.
  6. Transient = terms that die out (system poles inside |z| = 1). Steady-state = terms that last (input poles on |z| = 1).
  7. Remove the transient: set y[n] = yss[n] for all n; plug into the equation at n = 0 and n = 1; solve for y[−1], y[−2].
  8. Check: compute y[0], y[1] straight from the equation. Initial value: y[0] = limz→∞ Y+(z). (optional) Final value: y[∞] = limz→1(1 − z−1)Y+(z), only if all poles inside the unit circle except at most one at z = 1.

A system is LTI only if its initial conditions are zero.
