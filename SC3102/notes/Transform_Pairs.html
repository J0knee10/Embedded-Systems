Notes:
$u(t),\ u[n]$
= unit step function
$\operatorname{rect}(t)$
= rectangular function: $1$ for $|t|\lt\frac{1}{2}$, else $0$
$\delta(t)$
= Dirac delta function
$\operatorname{sgn}(t)$
= signum function
$\delta[n]$
= unit impulse ($1$ at $n=0$, else $0$)
$\operatorname{sinc}(x)$
= $\sin(\pi x)/(\pi x)$
$\sigma$
= $\operatorname{Re}(s)$
$\Omega$
= frequency in rad/sample; $X(\Omega)$ has period $2\pi$
✗
= does not exist (no ROC / no transform)
—
= not needed in SC3102 (exists, often only as a generalized function)
Laplace → CTFT:  $X(f)=X(s)\big|_{s=j2\pi f}$, valid when the ROC contains the $j\omega$-axis ($\sigma=0$).
Z → DTFT:  $X(\Omega)=X(z)\big|_{z=e^{j\Omega}}$, valid when the ROC contains the unit circle $|z|=1$.
The lecture slides write $e^{at}u(t)\leftrightarrow \frac{1}{s-a}$, $\sigma\gt a$. That is the same pair with $a\to -a$.
Same formula, different ROC, different signal: the ROC decides right-sided vs left-sided.
