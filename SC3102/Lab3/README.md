# Lab 3 — Fourier transforms

With Python 3.8, run in this folder:

```sh
python -m pip install -r requirements.txt
python -m notebook Lab-03-DFT.ipynb
```

Or with [uv](https://docs.astral.sh/uv/getting-started/installation/):

```sh
uv venv --python 3.8
uv pip install -r requirements.txt
uv run python -m notebook Lab-03-DFT.ipynb
```
